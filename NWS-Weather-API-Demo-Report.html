🔧 How We Did It

Identified the API

The NWS Weather API (api.weather.gov) is a free, public REST API returning JSON — a perfect fit for Custom Connectors. No API key required.

Created the Connector

Maia launched the Custom Connector wizard, read the API documentation URL, and auto-discovered endpoints, parameters, headers, and JSON response structures.

Reviewed Endpoints

13 endpoints were created automatically. 11 published successfully; 2 remain in draft (List Radar Queues, List Zones) due to missing structure — editable anytime in the connector workbench.

Built the Pipeline

Two connector components chained together: Get Grid Point (translates coordinates to NWS grid system) → Get Forecast (retrieves the 7-day forecast).

Parameterized with Variables

latitude and longitude pipeline variables make it reusable for any US location. Default set to Manhattan, NY (40.7128, -74.0060).

Sampled Raw Output

Live forecast data returned directly in the canvas — 14 periods with temperature, wind, precipitation, and detailed forecasts. Zero infrastructure needed.
