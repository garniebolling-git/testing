02 · AI oversight

Every Maia action is logged, and people approve each one

This section speaks to the CDO's concern about AI acting on bank data without supervision. Maia ran 19 tasks: 13 by the data engineer agent and 6 by the graph visualisation agent. Before Maia touched the warehouse, ran a pipeline or deleted a file, a person approved that single action, and the approval landed in the audit log with the tool name and conversation ID.

No approval granted Maia standing permission for the rest of a session. Each warehouse query and each pipeline run needed its own sign-off.

Approval bypass is visible

The permission preset DANGEROUSLY_SKIP_APPROVALS appeared twice in test work on 2026-09-18: once at task start (18:26 UTC) and once as a mid-task change (23:19 UTC). Both are in the log. A bank would alert on this event type and restrict the preset by role.

The platform emitted 45 lineage events in OpenLineage format, covering 12 pipelines and 12 Snowflake tables. Because the format is open, an enterprise catalog such as Alation, Collibra or Informatica CDGC can ingest these events without custom code.

Dashed amber lines: lineage also records TEAM and ENGINEERING_METRICS feeding EXBANK_DAILY_SUMMARY from an earlier version of t1-exbank-daily-metrics. The lineage log keeps history, so a catalog would show both versions until one is retired.

07 · Gaps and discovery questions

What a bank adds around the platform

The API does not cover every control a bank's second line of defense expects. Each gap below pairs the observation with the question to ask the customer.

Secrets

Secrets inventory does not match the audit log

The audit log shows 3 warehouse credentials created. The secret reference list returns 0.

Ask: Which vault holds your pipeline credentials today, and does audit need a single inventory across tools?

Classification

No sensitivity labels, owners or quality scores

Lineage ownership and documentation facets are empty. No PII tags or data quality results appear in any response.

Ask: Where do data classifications and stewards live today, and should lineage flow into that catalog?

Access

Project membership, not data entitlements

The audit log records users added to projects. The API does not report who holds read access to which table.

Ask: Are table entitlements managed in Snowflake roles, and who certifies them each quarter?

Hosting

Customer-hosted execution not shown

This account runs on a Matillion-hosted runner. A bank deployment keeps the runner and data plane inside the bank's own cloud account.

Ask: Which cloud and region must the runner live in, and what are the network egress rules?
